一、实验目的

掌握从简单到复杂的数据查询方法，熟悉单表查询、多表连接查询、嵌套查询和集合查询的写法，理解排序、分组、聚合函数以及模糊匹配等常见查询操作。

二、实验环境

使用 SQL Server 数据库管理系统，在教学数据库 jxsk 上通过企业管理器和 SQL 语句完成实验。

三、实验内容与过程

1. 查询 S 表中全体学生的详细记录。

USE jxsk
GO
SELECT * FROM S
GO

执行结果：返回学生表 S 中全部学生的详细信息，包括学号、姓名、性别、年龄和系别。

2. 查询所有学生的姓名及其出生年份。

SELECT SN, 2005-AGE FROM S
GO

执行结果：返回学生姓名和根据年龄推算出的出生年份。

3. 查询考试成绩有不及格的学生学号。

SELECT DISTINCT SNO FROM SC WHERE SCORE < 60
GO

执行结果：返回成绩低于 60 分的学生学号，重复学号被去除。

4. 查询年龄在 20 到 23 岁之间的学生姓名、系名和年龄。

SELECT SN, DEPT, AGE FROM S WHERE AGE BETWEEN 20 AND 23
GO

执行结果：返回符合年龄条件的学生信息。

5. 查询姓李的学生的姓名、学号和性别。

SELECT SN, SNO, SEX FROM S WHERE SN LIKE '李%'
GO

执行结果：返回所有姓李的学生记录。

6. 查询名字中第 2 个字为“明”字的男学生的姓名和系名。

SELECT SN AS 姓名, DEPT AS 系名
FROM S
WHERE SN LIKE '_明%' AND SEX='男'
GO

执行结果：返回姓名第二个字为“明”且性别为男的学生姓名及系别。

7. 查询信息系、计算机系学生的姓名、系名，结果按系名升序、姓名降序排序。

SELECT SN AS 姓名, DEPT AS 系名
FROM S
WHERE DEPT IN('信息','计算机')
ORDER BY DEPT, SN DESC
GO

执行结果：返回信息系和计算机系学生，并按要求排序。

8. 查询所有有课程号 C2 成绩的学生的学号、课程号和成绩，并按成绩降序排序。

SELECT SNO AS 学号, CNO AS 课号, SCORE AS 成绩
FROM SC
WHERE CNO='C2' AND SCORE IS NOT NULL
ORDER BY SCORE DESC
GO

执行结果：返回课程 C2 的成绩记录，并按分数从高到低排列。

9. 查询计算机系学生总人数。

SELECT COUNT(*) AS 总人数 FROM S WHERE DEPT='计算机'
GO

执行结果：统计并返回计算机系学生总人数。

10. 查询选修了微机原理课程的学生人数、平均成绩、最高成绩。

SELECT COUNT(*) AS 人数,
       AVG(SCORE) AS 平均分数,
       MAX(SCORE) AS 最高分数
FROM C, SC
WHERE CN='微机原理' AND C.CNO=SC.CNO
GO

执行结果：返回微机原理课程的选课人数、平均成绩和最高成绩。

11. 查询各个课程号及相应的选课人数。

SELECT CNO AS 课程号, COUNT(SNO) AS 人数
FROM SC
GROUP BY CNO
GO

执行结果：按课程号分组统计每门课程的选课人数。

12. 查询选修了 2 门以上课程的学生姓名和平均成绩。

SELECT SN AS 姓名, AVG(SCORE) AS 平均成绩
FROM S, SC
WHERE S.SNO=SC.SNO
GROUP BY S.SN
HAVING COUNT(*)>2
GO

执行结果：返回选课数超过 2 门的学生姓名及其平均成绩。

13. 查询所有选课学生的学号、姓名、选课名称及成绩。

SELECT S.SNO, SN, CN, SCORE
FROM S, C, SC
WHERE S.SNO=SC.SNO AND C.CNO=SC.CNO
GO

执行结果：通过多表连接返回学生、课程和成绩信息。

14. 查询每门课程的课程号、任课教师姓名及其选课人数。

SELECT C.CNO, TN, COUNT(SC.SNO) AS 学生人数
FROM T, TC, C, SC
WHERE T.TNO=TC.TNO AND
      C.CNO=TC.CNO AND
      C.CNO=SC.CNO
GROUP BY C.CNO, T.TN
GO

执行结果：返回每门课程的任课教师以及选课人数。

15. 查询所有比“刘伟”工资高的教师姓名、工资和刘伟的工资。

SELECT X.TN AS 姓名,
       X.SAL AS 教师工资,
       Y.SAL AS 刘伟工资
FROM T AS X, T AS Y
WHERE X.SAL > Y.SAL AND Y.TN='刘伟'
GO

执行结果：返回工资高于刘伟的教师名单及对应工资。

16. 查询同时选修了“程序设计”和“微机原理”的学生姓名、课程信息。

SELECT DISTINCT (SN) AS 姓名, C1.CN AS 课程名1, C2.CN AS 课程名2
FROM C AS C1, C AS C2, SC AS SC1, SC AS SC2, S
WHERE C1.CNO = SC1.CNO AND C2.CNO=SC2.CNO AND
      C1.CN='程序设计' AND C2.CN='微机原理' AND
      SC1.SNO=SC2.SNO AND SC1.SNO=S.SNO
GO

执行结果：返回同时选修两门指定课程的学生信息。

17. 查询所有学生的学号、姓名、选课名称及成绩，没有选课的同学选课信息显示为空。

SELECT S.SNO, SN, CN, SCORE
FROM S
LEFT OUTER JOIN SC ON S.SNO=SC.SNO
LEFT OUTER JOIN C ON C.CNO=SC.CNO
GO

执行结果：返回全部学生记录，未选课学生的课程名称和成绩显示为 NULL。

18. 查询与“刘伟”教师职称相同的教师号、姓名和职称。

SELECT TNO, TN, PROF
FROM T
WHERE PROF=(SELECT PROF FROM T WHERE TN='刘伟')
GO

执行结果：先查出刘伟的职称，再返回所有相同职称的教师。

19. 使用 ANY 与 IN 谓词查询讲授课程号为 C5 的教师姓名。

SELECT TN
FROM T
WHERE (TNO = ANY (SELECT TNO FROM TC WHERE CNO='C5'))
GO

SELECT TN
FROM T
WHERE (TNO IN (SELECT TNO FROM TC WHERE CNO='C5'))
GO

执行结果：两条语句均返回讲授课程号 C5 的教师姓名。

20. 使用 ALL 谓词查询其他系中比计算机系所有教师工资都高的教师姓名、工资和所在系。

SELECT TN, SAL, DEPT
FROM T
WHERE (SAL > ALL (SELECT SAL FROM T WHERE DEPT='计算机')) AND
      (DEPT <> '计算机')
GO

执行结果：返回工资高于计算机系全部教师工资的其他系教师信息。

21. 使用 EXISTS 谓词查询没有讲授课程号为 C5 的教师姓名、所在系。

SELECT TN, DEPT
FROM T
WHERE (NOT EXISTS (SELECT * FROM TC WHERE TNO=T.TNO AND CNO='C5'))
GO

执行结果：返回未讲授 C5 课程的教师姓名和系别。

22. 使用 NOT EXISTS 谓词查询至少选修了学生 S9 选修的全部课程的学生学号。

SELECT DISTINCT SNO
FROM SC SCX
WHERE NOT EXISTS
  (SELECT * FROM SC SCY
   WHERE SCY.SNO='S9' AND NOT EXISTS
     (SELECT * FROM SC SCZ
      WHERE SCZ.SNO=SCX.SNO AND SCZ.CNO=SCY.CNO))
GO

执行结果：返回至少包含学生 S9 全部选课的学生学号。

23. 查询计算机系的学生及年龄不大于 19 岁的学生。

SELECT * FROM S WHERE DEPT='计算机'
UNION
SELECT * FROM S WHERE AGE<=19
GO

执行结果：返回两个结果集的并集，重复记录自动去除。

四、思考题

1. 下面语句不正确，因为 SELECT 子句中的 CN、TN、PROF 都没有出现在 GROUP BY 子句中，且未使用聚合函数处理，违反了 SQL 的分组规则。

SELECT CN，TN，PROF，COUNT(SC.SNO)
FROM C，T，TC，SC
WHERE T.TNO=TC.TNO AND C.CNO=TC.CNO AND SC.CNO=C.CNO
GROUP BY SC.CNO

2. LIKE 谓词中正确的是 SN LIKE '欧阳_%'。其中“_”表示任意单个字符，“%”表示任意长度字符串，因此该写法可以表示以“欧阳”开头且后面至少还有一个字符的姓名。

3. ORDER BY 的作用是对查询结果排序。ORDER BY SN, SEX 表示先按姓名升序，再按性别升序；ORDER BY AGE, PROF DESC 表示先按年龄升序，再按职称降序。

4. GROUP BY 的作用是按指定字段进行分组。GROUP BY SEX 表示按性别分组；GROUP BY AGE, PROF 表示先按年龄分组，再按职称进一步分组。
