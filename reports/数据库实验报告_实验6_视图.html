一、实验目的

掌握视图的创建、修改、删除方法，理解视图与基本表之间的关系，掌握通过视图查询和更新基本表数据的基本操作及限制条件。

二、实验环境

使用 SQL Server 数据库管理系统，在 jxsk 教学数据库中通过企业管理器和 SQL 语句完成视图实验。

三、实验内容与过程

1. 用企业管理器创建视图 VIEW_S。

操作步骤：右键数据库中的“视图”，选择“新建视图”，添加表 S，选择字段 SNO、SN、SEX、DEPT，保存为 VIEW_S。

SELECT SNO, SN, SEX, DEPT FROM dbo.S

执行结果：成功创建视图 VIEW_S，用于显示学生的基本信息。

2. 用企业管理器创建视图 VIEW_SCORETABLE。

操作步骤：新建视图并添加表 S、SC、C，设置连接条件 S.SNO=SC.SNO 和 SC.CNO=C.CNO，选择字段 SN、CN、SCORE，保存视图。

SELECT dbo.S.SN, dbo.C.CN, dbo.SC.SCORE
FROM dbo.S INNER JOIN
     dbo.SC ON dbo.S.SNO = dbo.SC.SNO INNER JOIN
     dbo.C ON dbo.SC.CNO = dbo.C.CNO

执行结果：成功创建视图 VIEW_SCORETABLE，可直观显示学生姓名、课程名和成绩。

3. 用 SQL 创建视图 VIEW_CTABLE。

USE jxsk
GO
CREATE VIEW VIEW_CTABLE
AS SELECT TN, CN, CT FROM T, C, TC
WHERE T.TNO=TC.TNO AND C.CNO=TC.CNO
GO

执行结果：成功创建 VIEW_CTABLE，显示教师姓名、课程名称和课时。

4. 通过视图 VIEW_S 修改基本表 S 的数据。

操作步骤：打开 VIEW_S，修改某学生的 DEPT 字段，例如将“计算机”改为“外语”，然后保存。

执行结果：修改成功，基本表 S 中对应记录也同步发生改变。

5. 对视图 VIEW_S 执行 INSERT 语句，观察失败原因。

INSERT INTO VIEW_S VALUES('古明','男',18,'自动化')
GO

执行结果：插入失败。原因是原视图未包含基本表主键 SNO，无法完成合法插入。

6. 修改视图定义后重新执行插入操作。

ALTER VIEW VIEW_S
AS SELECT SNO, SN, SEX, DEPT FROM S
GO

INSERT INTO VIEW_S VALUES('S8','古明','男','自动化')
GO

执行结果：插入成功，说明当视图包含主键且来源于单表时，可以通过视图向基本表插入数据。

7. 对视图 VIEW_S 执行 UPDATE 语句。

UPDATE VIEW_S SET DEPT='计算机' WHERE SN='古明'
GO

执行结果：更新成功，基本表 S 中“古明”的系别被改为“计算机”。

8. 用企业管理器修改视图 VIEW_S，删除 DEPT 字段。

操作步骤：右键视图 VIEW_S，进入设计视图，取消选择 DEPT 字段后保存。

SELECT SNO, SN, SEX FROM dbo.S

执行结果：视图修改成功，显示列中不再包含 DEPT。

9. 用 SQL 修改视图 VIEW_CTABLE。

USE jxsk
GO
ALTER VIEW VIEW_CTABLE
AS SELECT TN, CN, CT FROM T, C, TC
WHERE T.TNO=TC.TNO AND C.CNO=TC.CNO
GO

执行结果：视图 VIEW_CTABLE 修改成功，结果中包含课时字段 CT。

10. 删除视图 VIEW_S 和 VIEW_CTABLE。

操作步骤：可在企业管理器中删除 VIEW_S。

USE jxsk
DROP VIEW VIEW_CTABLE
GO

执行结果：成功删除视图 VIEW_CTABLE，VIEW_S 也可通过企业管理器删除。

四、思考题

1. “视图只能来源于基本表，不能来源于已有视图”这一说法是错误的。视图既可以基于基本表创建，也可以基于已有视图创建，只要依赖关系合法即可。

2. 视图中的数据并非都可以修改。通常只有来源于单个基本表、包含主键字段，且不包含聚合函数、DISTINCT、GROUP BY 等复杂结构的视图，才可能支持更新操作。

3. 不是所有视图都具有通过其修改基本表数据的性质。一般不能更新的视图包括：由多个基本表连接形成的视图、含有聚合函数的视图、含有 DISTINCT 或 GROUP BY 的视图、字段来源于表达式或常量的视图，以及建立在不可更新视图之上的视图。

五、实验总结

通过本次视图实验，我掌握了视图的创建、修改和删除方法，并理解了视图作为“虚表”在数据库系统中的重要作用。视图能够简化复杂查询，提高用户使用数据库时的便利性，同时也有助于隐藏部分基础数据，提高数据访问的安全性。

在实验过程中，我重点体会到了可更新视图的使用条件和限制。只有满足一定条件的视图，才能通过 INSERT、UPDATE 等语句间接修改基本表数据。通过本次实验，我对数据库逻辑结构和用户外部模式有了更深理解，也认识到视图在实际开发和数据库管理中的重要价值。
